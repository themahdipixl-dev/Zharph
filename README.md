# Zharph

Material 3 wallpaper app built with Expo SDK 55.

## Current experience

- Minimal Zharph header.
- Horizontal Material 3 category tabs.
- Three-column wallpaper grid.
- First tile is always the user's add-photo tile.
- Selecting either a preset or personal photo opens the editor.
- Editor starts with Depth, Blur, Crop, and Adjust tools.
- Bottom navigation is present as a placeholder for future sections.
- Android 12+ uses Expo's official Material 3 Dynamic Colors API, so the app palette follows the device wallpaper/system theme.

## Run

```bash
npm install
npx expo start
```
